# SecureBooking

Sistema web de gestión de reservas desarrollado con:

- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: Node.js + Express
- Base de datos: MySQL (XAMPP)

## Funcionalidades
- Registro e inicio de sesión
- Creación de reservas
- Edición y eliminación de citas
- Sistema de autenticación con bcrypt

## Ejecución
1. Abrir backend
2. npm install
3. npm run dev
4. Abrir frontend/home.html
